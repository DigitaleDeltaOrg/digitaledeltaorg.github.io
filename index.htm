Digitale Delta API

De Digitale Delta API is een set van afspraken waarmee verschillende informatiesystemen op een gestandaardiseerde en veilige manier waterdata met elkaar delen.

Het doel van de Digitale Delta API (DD API) is om een bijdrage te leveren aan de goede kwaliteit van waterbeheer. Door gegevens efficiënt met elkaar te delen, kan waterbeheer slimmer en doeltreffender worden uitgevoerd, zelfs over de grenzen van verschillende beheergebieden heen. De gegevensuitwisseling kan plaatsvinden tussen alle partijen die een rol spelen in de waterketen, van laboratoria, sensor-data-partijen, waterleidingsbedrijven en waterzuiveringsinstellingen tot onderzoekers én het Informatiehuis Water.

Digitale Delta API 3.0

In versie 3.0 van de Digitale Delta API-specificatie zijn verschillende varianten van de DD API geïntegreerd tot één sterke API voor de watersector.

De DD API-specificatie 3.0 is breed toepasbaar. De uitwisseling van verschillende soorten meetdata (zoals tijdreeksen, rasterdata en verwachtingen) wordt ondersteund voor meerdere toepassingsgebieden (waterkwaliteit, waterkwantiteit, ecologie en waterzuivering). De zoek- en filtermechanismen zijn voor al deze toepassingen hetzelfde.

De Digitale Delta API 3.0 omvat een open en niet merk-, omgevings- of systeemgebonden specificatie die door iedereen vrij gebruikt kan worden zonder licentie. Er is ook een open source implementatie beschikbaar die als uitgangspunt kan worden gebruikt door aanbieders.

De Digitale Delta API V3 is winnaar van de Gouden API 2026.

Daarmee is de DD API uitgeroepen tot de beste implementatie van een API in de publieke sector van dit jaar.

Aan welke standaarden voldoet de DD API 3.0?

De DD API-specificatie is gebaseerd op OM&S (de 19156:2023 standaard voor Observations, Measurements and Samples) en voldoet aan diverse (inter)nationale standaarden die van belang zijn voor gegevensuitwisseling binnen en door de watersector, zoals OData, CoverageJSON, OAuth2.0 en de standaard voor API's van het Forum Standaardisatie.

Voor de betekenis van de datavelden wordt gebruik gemaakt van de termen en definities uit:

  • de Aquo-standaard voor waterdata
  • de TWN-lijst (Taxa Waterbeheer Nederland)
  • de door het KNMI gevolgde richtlijnen van de Wereld Meteorologische Organisatie (WMO)

Technische beschrijvingen

De Digitale Delta formaten (DD API V2, DD-ECO-API en DD API V3) zijn technische beschrijvingen.

Voor meer informatie hierover, kunt u de volgende pagina's raadplegen:

API Omschrijving
DD API V2 Tijdsreeksen (chemisch, fysisch)
DD-ECO-API Observaties (ecologisch, chemisch, fysisch)
DD API V3 OData en OM&S gebaseerd: Observaties, tijdseries, roosters, verwachtingen en ensembles (ecologisch, chemisch, fysisch)
De DD API is volop in ontwikkeling: DD API V4 in de steigers.
Begin van Q4 2026 wordt deze in consultatie gebracht en gepubliseerd op GitHub.
Wijzigingen zullen in grote lijnen zijn:
  • Meer in lijn brengen met de onderliggende standaarden
  • Introductie van een taalschakelaar om bepaalde elementen van het formaat tussen Engels en Nederlands te kunnen laten schakelen
  • Verbetering van het ingebouwde referentiesysteem, met specifieke endpoints voor geografie met ondersteuning voor JSON-FG
  • Schakelbare semantiek
  • Verbeterde ondersteuning voor tijdreeksen, verwachtingen en ensembles

V3 en V4 zullen tezamen actief onderhouden worden.

DD API V3 Tookit De ToolKit is een cross-platform .NET-project voor een `DD API V3` implementatie. De versie van .NET is 10, een zogenaamde LTS-versie (Long Term Support). De bedoeling is dat zo min mogelijk code moet worden geschreven om een werkende DD API V3 implementatie te maken. Alles wordt via configuratie geregeld. Het kan probleemloos als container draaien.
